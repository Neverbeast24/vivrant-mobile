# VIVA — Virtual Intelligent Vitality Assistant

**Tagline:** Every Choice Shapes Your Health.

## Mission
Help people make smarter daily health decisions through personalized recommendations instead of simply tracking data.

## Project Overview
VIVA is an AI-powered Health Decision Support System that analyzes a user's goals, nutrition, workouts, spending habits, and lifestyle to recommend the best next action.

## Problem Statement
Most fitness applications collect health data but do not guide users toward the best decision for their personal situation.

## Research Gap
Existing systems answer **"What happened?"**. VIVA answers **"What should I do next?"** using an intelligent Decision Engine.

## Core Modules
- Goal Setup
- Decision Engine
- Nutrition Tracker
- Workout Tracker
- Health Expense Tracker
- Pantry & Grocery Planner
- AI Recommendations
- Weekly Reports
- Notifications

## Research Contribution
- Decision Score
- Goal Alignment Score
- Health Investment Index

These proposed metrics evaluate daily health decisions instead of only tracking calories or expenses.
